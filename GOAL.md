# Project Mission & Architecture Core

## 🎯 Primary Goal
Build a web-scale, continuous intelligence engine to discover, extract, deduplicate, and index **millions to billions of real, 100% verified people profiles** across the web.

## 🔑 Core Requirements
1. **Maximum Scale & Throughput**: Continuous 24/7 ingestion powered by distributed GitHub Actions matrix runners, Exa.ai neural search, and high-throughput bulk batch APIs.
2. **100% Data Accuracy & Integrity**: Zero placeholder data, zero hallucinated links, and mandatory RFC 5322 email and URL regex validation.
3. **Identity Resolution**: GPT-5.6 Terra multi-source entity merging into unified canonical person nodes.
4. **Outreach Status**: Out of scope for current phase — 100% of compute focused on scale, accuracy, and storage efficiency.
